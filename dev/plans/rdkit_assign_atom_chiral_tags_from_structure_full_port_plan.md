## Exact Scope

- The RDKit Python name `AssignAtomChiralTagsFromStructure` is the wrapper at `third_party/rdkit/Code/GraphMol/Wrap/MolOps.cpp:2390-2409`; it calls `RDKit::MolOps::assignChiralTypesFrom3D`, declared at `third_party/rdkit/Code/GraphMol/MolOps.h:1089-1105` and defined at `third_party/rdkit/Code/GraphMol/Chirality.cpp:3377-3500`.
- The port includes every active helper and header-defined numeric behavior transitively used by that function: `getValFromEnvironment`, `getAllowNontetrahedralChirality`, `bondAffectsAtomChirality`, `getAtomNonzeroDegree`, `isWigglyBond`, `VOLTEST`, `OctahedralPermFrom3D`, `assignNontetrahedralChiralTypeFrom3D`, and the used `RDGeom::Point3D` operations.
- The port includes tetrahedral, sulfur/selenium, square-planar, trigonal-bipyramidal, square-pyramidal, octahedral, explicit-tag, environment-control, conformer-selection, property, mutation-order, and structured-error behavior observable at this entry point.
- The port does not include `assignStereochemistryFrom3D`, double-bond direction detection, E/Z assignment, CIP filtering, or validation that substituents are distinct; those are separate RDKit entry points and must not be silently folded into this operation.
- Official RDKit is a test-data oracle only and must not become a production dependency, FFI path, external-command fallback, or runtime subprocess.
- The current per-atom bond-table scans may retain a second-axis `❌` until adjacency-backed iteration is implemented; behavioral completion must not falsely upgrade that performance marker.

## Known Baseline Gaps To Verify In Step 3

- `crates/cosmolkit-core/src/chemistry/stereo.rs:3760-3834` exposes a heuristic function with a fabricated abbreviated source frame and an `is_opposite_bonds()` implementation that always returns `true`; it is not the RDKit 3D entry point and must not survive as production behavior.
- `crates/cosmolkit-core/src/notation/smiles/stereo.rs:2843-3067` contains a substantial internal port, but currently omits `replaceExistingTags`, always enables non-tetrahedral assignment, clears `_StereochemDone` in the wrong order for a non-3D conformer, treats dative and wiggly bonds without RDKit's atom-direction condition, converts zero-length direction-vector exceptions to `None`, and has no direct full-field RDKit oracle.
- Existing source-focused tests cover useful branches, but they do not establish exact parity for the complete public parameter and observable-state matrix.
