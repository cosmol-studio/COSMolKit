# Development Archive

This directory preserves superseded roadmaps, inactive execution plans, and
their generation tools as historical evidence.

Archived documents are not normative, are not current status claims, and must
not be used as an execution queue. Their source references, marker states, and
checked steps remain evidence of what was reviewed at the time. Current rules
are defined by the Markdown documents at the `dev/` top level; current work is
listed in [`../plans/`](../plans/).
