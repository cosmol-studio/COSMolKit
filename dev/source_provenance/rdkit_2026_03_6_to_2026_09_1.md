# RDKit 2026.03.6 to 2026.09.1: Source Upgrade Checklist

This checklist records the upstream changes reviewed for the upgrade.
The specification is the direct source diff, not corpus-output fitting.

| Reference | Version | Source commit |
|---|---|---|
| Baseline | `Release_2026_03_6` | [`0e0d85f4ca34`](https://github.com/rdkit/rdkit/commit/0e0d85f4ca34aeae15dfc0f7cf5503bdb0a8e985) |
| Upgrade | `Release_2026_09_1` | [`fece8caa860b`](https://github.com/rdkit/rdkit/commit/fece8caa860bdf6c9c82bdb9253f22a0cf87150c) |

## Chemistry and notation

| Item | Upgrade check |
|---|---|
| CHEM-01 | Iterative fused-ring DFS preserves traversal order and avoids recursive stack growth. |
| CHEM-02 | RDL SSSR and relevant cycles; normalized cycle ordering; backend selection; retained ring families and selective reset. |
| CHEM-03 | Sanitization stage order and aromatic hydrogen mask; retain the separate unmasked tautomer-product adjustment. |
| CHEM-04 | Degree-aware `_AP<n>` labels in parser cleanup; distinguish numbered labels from ATTCHPT values and attachment expansion/collapse. |
| CHEM-05 | Atom/bond enum widths, non-tetrahedral initialization and C++ ABI cleanup; preserve explicit CK persistence tags. |
| CIP-01 | Whole-molecule auxiliary configurations, selected primary labels, property clearing and full-versus-partial `_CIPComputed` semantics. |
| CIP-02 | Cumulative user comparison budget, per-center preliminary limit and scoped interruption lifetime. |
| CIP-03 | Raw fractional atomic numbers, complete resonance-part sums and ring-only pruning. |
| CIP-04 | Wider graph depths, allocation-time node cap and explicit isotope fallback. |
| CIP-05 | Configuration eligibility, invalid carriers, ordered-index bounds and atropisomer pseudo-label XOR. |
| CIP-06 | Sorter ownership and hot-path allocation costs; retain rule order and comparisons. |
| STEREO-01 | Shared atropisomer detection, replacement policy, ring-size cleanup and parser/stereo caller ownership; retain the pointer-order platform boundary. |
| STEREO-02 | Structured potential-stereo comparison keys, numeric discriminators and reusable canonical state. |
| CANON-01 | Contiguous canonical neighbor storage and small bond holders, preserving neighbor order and comparison semantics. |
| SMILES-01 | Ignore atom maps only for canonical ranking; preserve maps in output and noncanonical traversal. |
| SMILES-02 | Direct text assembly, retained vector capacity and moved fragment text/index buffers; preserve fragment and closure order. |
| CX-01 | Context-specific quoting, permissive numeric conversion and shared attachment cleanup; keep overflow and byte-signedness boundaries explicit. |
| TAUT-01 | Preserve unknown double-bond stereo and reject complete transform matches touching protected atoms. |
| TAUT-02 | Canonical ties compare score, specified-stereo count, then lexical SMILES; retain lazy key evaluation. |
| QUERY-01 | Recursive-query initialization, copied query state and preinitialized membership lifetime; distinguish call-local matching from persistent iterators. |
| SEARCH-02 | Scoped cancellation in search, CIP, conformer generation and bond determination, respecting native/WASM boundaries. |
| RING-ORDER-01 | Stable RDL cycle-family and DIMACS sorting, including equal-comparing rows. |

## Geometry and force fields

| Item | Upgrade check |
|---|---|
| CONF-01 | UFF squish requires both endpoints; propagate bond intervals and angular bounds into 1–3 distances. |
| CONF-02 | Distinct cis/trans path classification, forced macrocycle policy and interval propagation through 1–4/1–5 bounds. |
| CONF-03 | Bounds precede torsion setup; forced amide/ester terms have priority; retain the first contribution per central bond. |
| CONF-04 | Treat ETKDGv4/Gaussian torsions, internal-coordinate embedding, MMFF embedding bounds, initial-only output and AIO changes as separate capability scope. |
| DEPICT-01 | Full-circle angular gaps, reference-direction placement and actual segment collision handling. |
| DEPICT-02 | Default-enabled path-angle expansion, side traversal, rollback and iteration/angle limits. |
| DRAW-01 | Degenerate linear-atom behavior; distinguish query-list/color-JSON extensions from existing rendering. |
| FF-01 | Dihedral clamp preserves NaN; retain finite arithmetic and contribution/gradient order. |
| ALIGN-01 | Distinguish the new rectangular probe/reference conformer RMS matrix from the existing within-molecule triangular matrix. |

## Other reviewed scope

| Item | Upgrade check |
|---|---|
| FRAGMENT-01 | Count every cut incident on an atom in bond-cutting APIs; do not confuse this with connected-component fragmentation. |
| REACTION-01 | Reaction-specific changed hunks retain runner semantics; review parser allocation changes and shared ring/stereo/query effects separately. |
| DESCRIPTOR-01 | Correct `chi2v`/`chi2n` dispatch; classify DCLV point output and Bertz bond-type interpretation separately from existing descriptors. |
| IO-01 | RDKit pickle 16.4 index widths and ring-family restoration are distinct from CK native archive contracts. |
| IO-02 | Safe SDF framing and last-`>` property headers; distinguish C++ supplier ownership and SMILES-table features from CK readers. |
| IO-03 | CDXML/ChemDraw query labels, constraints, strictness, attachments and reaction annotations are independent format scope. |
| SCOPE-01 | Separately classify MacroMol, Gaussian shape, DCLV, MolCatalog, SynthonSpace and PostgreSQL cartridge additions. |
| SHARED-01 | Fixed-width aliases, property alternatives, fingerprint rules, inactive code and build cleanup do not imply new chemistry or archive schemas. |
| WRAPPER-01 | Review changed native calls/defaults under their domain owners; do not reproduce nanobind, Boost.Python or embind machinery in CK bindings. |
