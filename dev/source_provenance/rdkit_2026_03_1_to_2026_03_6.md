# RDKit 2026.03.1 to 2026.03.6: Source Diff Audit

This inventory records source-level implementation changes identified by comparing the pinned RDKit revisions. The upgrade is driven by upstream implementation diffs, not by fitting COSMolKit to corpus outputs. Local regressions check the reproduced branches; corpus comparisons are validation evidence, not algorithm specifications.

| Reference | Previous pin | Updated pin |
|---|---|---|
| RDKit release | `2026.03.1` | `2026.03.6` |
| Source revision | `351f8f378f8ad6bbd517980c38896e66bf907af8` | `0e0d85f4ca34aeae15dfc0f7cf5503bdb0a8e985` |
| Python distribution | `2026.3.1` | `2026.3.6` |

The source submodule, both reference identity manifests, and the development Python dependency use the updated pin. The 51 groups below identify 197 required upstream diff hunks. Group descriptions retain their local scope; they are not a whole-library validation claim.

## Current reference and historical provenance

COSMolKit 0.5.0 uses the updated pin in the development dependency and lockfile,
the standard parity registry, both reference manifests and the RDKit source
tree. RDKit reports runtime version `2026.03.6`; package metadata uses
`2026.3.6`. These spellings identify the same release.

References to `2026.03.1` in frozen fixture provenance, original source
anchors and 0.3.0 validation records identify where those artifacts came
from; they do not override the current pin. In particular, the historical
ChEMBL audit scripts/profile and the standalone Pattern, Layered, descriptor
and stereoisomer benchmark scripts retain their old `.1` guards and API
contracts. They are not 0.5.0 validation entrypoints. Replacing those guards
without reviewing the associated schemas and APIs would mislabel evidence.

No differences have been observed on the known corpus of several hundred
thousand molecules. Million-scale 0.5.0 parity validation is pending.

## Method and integration

Review starts from the upstream source diff and follows each changed function's helpers, callers, data tables and error paths. Implementing functions carry verbatim source anchors and separate behavior/complexity markers under [the source-reproduction protocol](../source_reproduction_protocol.md). Fixed regressions belong at their smallest stable owner boundary; prepared corpus and designated special-regression comparisons belong to the standard parity runner. Expectations are not relaxed or regenerated to fit COSMolKit.

The upgrade preserves COSMolKit's approved public names, generated operation contracts, block-level COW and failure atomicity. Public tautomer queries and value transforms do not write caches back to the caller; source-required working-cache updates stay detached.
