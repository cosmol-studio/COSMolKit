ConfSeq
=======

.. meta::
   :description: ConfSeq availability and the supported Python 3D conformer workflow in COSMolKit 0.5.0.

The COSMolKit 0.5.0 Python module does not expose ConfSeq record decoding.
For 3D conformer generation, use ``Molecule.with_3d_conformer()`` or
``Molecule.with_3d_conformers()`` with ``EmbedParams``. See
:doc:`forcefields` for coordinate preparation and optimization, and
:doc:`api` for the exported interfaces.
