# RDKit depictor default template asset

`default_templates.cxsmarts` is the complete 578-row, source-order
`TEMPLATE_SMARTS` table from pinned RDKit 2026.03.1
`Code/GraphMol/Depictor/TemplateSmarts.h`. That upstream file is automatically
generated by the RDKit molecular-templates project and carries the notice
"Copyright (C) 2023 Schrödinger, LLC". RDKit's BSD license is
`third_party/rdkit/license.txt`. This data is used only for the depictor
default-template behavior; it is not a replacement for the upstream source.

Regenerate deterministically from the pinned submodule with
`.venv/bin/python tools/testdata/rdkit/prepare_depict_templates.py`.
The script rejects unexpected source syntax or row counts. Tests consume the
prepared asset read-only and do not access `third_party/` at runtime.
